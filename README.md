# 🧮 Simple Calculator

A responsive and user-friendly **Simple Calculator** built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations with a clean and modern interface.

---

## 📖 Project Overview

The Simple Calculator is a lightweight web application that allows users to perform standard mathematical calculations directly in the browser. It is designed with a responsive UI and interactive buttons for a smooth user experience.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖ Multiplication
- ➗ Division
- 📊 Percentage Calculation
- 🗑 Clear Display (AC)
- ⌫ Delete Last Character (DEL)
- 🔢 Decimal Number Support
- 📱 Responsive Design
- ⚡ Fast and Easy to Use

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run the Project

1. Download or clone the repository.

```bash
git clone https://github.com/adityakadamcloud/simple-calculator.git
```

2. Open the project folder.

3. Double-click **index.html**
   **OR**
   Open it using **Live Server** in Visual Studio Code.

---

## 💻 Calculator Functions

| Button | Function |
|---------|----------|
| AC | Clears the display |
| DEL | Deletes the last entered character |
| % | Percentage calculation |
| ÷ | Division |
| × | Multiplication |
| - | Subtraction |
| + | Addition |
| = | Displays the result |
| . | Decimal point |
